Consejos

Buenas prácticas para prompts más claros

Define la atmósfera

Menciona luz, color y contexto para guiar el resultado con menos ambigüedad.

Limita el alcance

Es mejor pedir un solo estilo fuerte que mezclar demasiadas ideas en una frase.

Ajusta por iteración

Cambia primero el prompt y luego la intensidad para entender el impacto de cada control.
